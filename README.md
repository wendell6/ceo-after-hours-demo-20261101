# 总裁，请下班

原创虚构成年角色的 90 秒互动演示。评论采用预设意图匹配；三类免费模拟礼物，各有三级表演；模拟观众、暂停与回合结算。

页面及配音素材预先生成。每位访客独立试玩，无真实支付、抖音接入或真实多人联机。

静态运行：`python3 -m http.server 8794`。
